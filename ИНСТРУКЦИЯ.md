# TournamentLive — инструкция по запуску (runbook)

Полный справочник контрактов и API: [`docs/RELAY.md`](docs/RELAY.md). Ниже — пошагово, «что делать в следующий раз».

## Адреса (шпаргалка)

| Что | Адрес |
|---|---|
| Веб-коктпит (панель управления) | http://localhost:8000 |
| Прямой плеер **выхода** (то, что видит площадка) | http://localhost:8888/broadcast/a .. /h |
| Прямой плеер **входа** (с телефона) | http://localhost:8888/tatami/a .. /h |
| RTMP, куда пушат телефоны | `rtmp://<LAN-IP>:1935/tatami/<а..h>` |
| HTTP API статусов | http://localhost:9997/v3/paths/list |

Ключи площадок живут в `outputs/outputs.local.conf` (gitignored, в git не попадает).
Редактируются **из панели** (секция «Площадки») — relayer перечитывает файл каждые ~3 с, без рестарта.

## Порядок запуска (полный чек-лист)

### 1. Поднять систему

```powershell
# ВАРЕНТ А: с 8 тестовыми «телефонами» (проверка без реальных устройств)
powershell -ExecutionPolicy Bypass -File scripts/start-all.ps1

# ВАРЕНТ Б: для реальных телефонов — без фейковых потоков
docker compose up -d --build
```

Если Docker отвечает `500 Internal Server Error` — перезапустить Docker Desktop
(закрыть процессами `Docker Desktop`/`com.docker.*`, запустить заново, подождать 1–2 мин,
проверить `docker info`), затем повторить команду.

Проверка: `docker compose ps` — все 4 контейнера `Up`:
`tl-mediamtx`, `tl-panel`, `tl-supervisor`, `tl-relayer`.

### 2. Подключить телефоны (реальные)

Сгенерировать QR (`tools/qr.html` в браузере), на каждое татами свой:

- `stream_url` = `rtmp://<LAN-IP-этой-машины>:1935/tatami/`
- `stream_key` = буква татами (`a`..`h`)

LAN-IP (меняется вместе с сетью, **не localhost**):

```powershell
(Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -like '192.168.*' }).IPAddress
```

Тестовые фейковые телефоны (только для проверки, не в бой):

```powershell
powershell -File scripts/start-test-streams.ps1   # запуск
powershell -File scripts/stop-test-streams.ps1    # остановка
```

### 3. Включить ретрансляцию на площадки (ключи)

1. Панель http://localhost:8000 → секция **«Площадки»**.
2. Для нужного татами выбрать платформу и заполнить поле:
   - **YouTube** — вставить **только ключ** (часть URL после `live2/`),
     т.е. из `rtmp://a.rtmp.youtube.com/live2/XXXX-...` берём `XXXX-...`.
     Полный URL в поле ключа НЕ вставлять — адрес склеится дважды и ffmpeg не подключится
     (симптом: в логах relayer повторяется `relay a (re)connecting` + `I/O error`).
   - **«VK Video»** (вариант в панели) — это на самом деле **Одноклассники**
     (`rtmp://ovsu.okcdn.ru/input/`), ключ от ОК.
   - **Реальный ключ VK** — выбрать «Другая (полный URL)» и вставить полный RTMP-адрес
     с ключом, который выдаёт VK в настройках трансляции.
   - если ключа нет вовсе — строка останется пустой, ретрансляции по ней не будет.
3. Поставить галочку **«вкл»** → **«Сохранить площадки»**.
   - Если вместо «✓ сохранено» вылезает «✗ ошибка»/таймаут — **сначала проверить, что файл
     всё равно записался**: `Get-Content outputs/outputs.local.conf`. Если строки на месте —
     relayer подхватит их через ~3 с, рестарт не нужен.
4. **Контроль**: `docker compose logs -f relayer`.
   - Успех: `relay a -> rtmp://a.rtmp.youtube.com/live2/<ключ>` и **больше никаких ошибок**
     по этой букве (ffmpeg подключился и молчит).
   - Неудача: повторяющиеся `Error opening output ...` — ключ неверен/истёк или URL сломан.
5. На самой площадке трансляция появляется через 10–30 с.

Формат файла (если править руками — потом проверять `docker compose logs -f relayer`):

```
a rtmp://a.rtmp.youtube.com/live2/XXXX-ключ
b rtmp://ovsu.okcdn.ru/input/ключ
#b rtmp://...        <- '#' в начале строки = выключено
```

### 4. Управление в эфире (панель, по карточке татами)

- **«Показать живое видео»** — превью (HLS) по клику.
- **«Завершить»** — выход `broadcast/<x>` уходит в offline, заставка НЕ включается;
  площадка корректно показывает «трансляция завершена».
- **«Возобновить»** — вернуть live/fallback-логику.
- Не идёт на площадку, а телефон в эфире — снять/поставить «вкл» в «Площадках» и
  дождаться «✓ сохранено».

### 5. Остановка

```powershell
powershell -ExecutionPolicy Bypass -File scripts/stop-all.ps1   # весь стек + ffmpeg
```

## Непрерывность выхода (live ↔ заставка)

Когда телефон пропадает, выход не рвётся: автоматически включается зацикленная заставка
(`fallback/fallback_<x>.mp4`), при восстановлении — возврат в live (дыра ~1–2 с, замена
ffmpeg-фидера; ограничение MVP).

Проверка:

1. Забить ffmpeg одного тестового телефона:
   ```powershell
   Get-CimInstance Win32_Process -Filter "Name='ffmpeg.exe'" |
     Where-Object { $_.CommandLine -like '*tatami/a*' -and $_.CommandLine -notlike '*broadcast*' } |
     ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
   ```
2. В панели: вход татами A — **OFF**, выход A — **ONLINE / FALLBACK**, остальные не тронуты.
3. Запустить телефон обратно (`start-test-streams.ps1`) — через пару секунд **FALLBACK → LIVE**.
4. В `logs/supervisor.log` — `mode live->fallback` / `fallback->live`.

## Грабли (проверено на живом стеке)

| Симптом | Причина / лечение |
|---|---|
| Docker: `500 Internal Server Error` на всё | движок в битом состоянии → перезапустить Docker Desktop (см. п.1) |
| Ключ вставил, «✓ сохранено», а на площадку ничего не идёт | старый relayer выбирал файл конфига только на старте — **собрали фикс: relayer перечитывает выбор файла каждые 3 с**. Если запускаете старое изображение: `docker compose up -d --build relayer` |
| В логах relayer `relay a (re)connecting` + `I/O error` | сломанный URL: в поле ключа вставили полный URL вместо ключа (адрес удвоился). Переписать ключ в панели (см. п.3) |
| В панели «VK Video», а это ОК | вариант «VK Video» = `ovsu.okcdn.ru` (Одноклассники). Реальный VK — «Другая (полный URL)» |
| Тестовые потоки ушли в реальные площадки | перед тестами `Move-Item outputs/outputs.local.conf outputs.local.conf.paused`, после — вернуть |
| Правка `mediamtx/mediamtx.yml` / `panel/index.html` не применяется | одиночные file-маунты: `docker compose up -d --force-recreate mediamtx panel` |
| Телефон не может подключиться | в QR LAN-IP, а не localhost; фаервол (`Setup-Firewall.bat`); IP сменился с сетью |
| Два фидера «дёрут» один broadcast | не запускать легаси `scripts/supervisor.ps1` вместе с контейнером `supervisor` |
| «✗ ошибка сохранения» в панели, но файл записался | проверить `Get-Content outputs/outputs.local.conf` — если строки верные, relayer подхватит сам через ~3 с |

## Безопасность

- `outputs/outputs.local.conf` — личные ключи площадок. В git не попадает (`.gitignore`).
  Если ключ попал в чат/скриншот — считать скомпрометированным и перевыпустить на площадке.
- API MediaMTX открыт (`user: any`) — только локально. Для VPS: реальные auth + TLS + фаервол.
